# Gift Upgrade Feed — бот с подпиской Telegram Stars

Этот комплект добавляет к aiogram-боту:

- платный доступ к списку через подписку Telegram Stars на 30 дней;
- команды `/subscribe`, `/gifts`, `/status`, `/cancel_sub`, `/resume_sub`;
- хранение подписчиков и новых подарков в SQLite;
- Telethon-слушатель событий `MessageActionStarGiftUnique` с флагом `upgrade`;
- уведомления активным подписчикам о новых апгрейдах, которые получает подключённый Telegram-аккаунт.

## Важное ограничение

Это **не глобальная лента всех апгрейдов Telegram**. Telethon-аккаунт получает только те события, которые Telegram доставляет этому аккаунту в чатах, к которым у него есть доступ. Бот сам по себе не видит все апгрейды всех пользователей.

## Установка на Windows

1. Распакуй архив в папку проекта.
2. Открой PowerShell в этой папке.
3. Создай виртуальное окружение (необязательно, но рекомендуется):

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

4. Установи библиотеки:

   ```powershell
   python -m pip install -r requirements.txt
   ```

5. Скопируй `.env.example` в `.env`:

   ```powershell
   Copy-Item .env.example .env
   ```

6. Открой `.env` и заполни `BOT_TOKEN`, `API_ID`, `API_HASH`. Укажи цену в `SUBSCRIPTION_STARS`.
7. Запусти пример:

   ```powershell
   python main_example.py
   ```

При первом запуске Telethon попросит номер телефона и код входа Telegram. Введи их только в локальной консоли на своём компьютере. Пароль двухэтапной проверки вводится там же, если Telegram его запросит. Не отправляй коды, пароль или файл сессии другим людям.

После успешного входа появится файл `gift_listener_session.session`. Он даёт доступ к авторизованной сессии Telegram — не публикуй и не пересылай его. Добавь `.env`, `*.session` и `*.sqlite3` в `.gitignore`, если используешь Git.

## Подключение к существующему main.py / Mini App

**Не заменяй свой `main.py` файлом `main_example.py`.** Это только пример самостоятельного запуска. В своём текущем `main.py` используй уже существующие объекты `bot` и `dp`:

```python
from paid_gifts import register_paid_gifts, start_gift_listener

# После создания существующих bot и dp:
register_paid_gifts(dp, bot)

# Внутри async main(), до start_polling:
telethon_client = await start_gift_listener(bot)

# Дальше оставь свой существующий запуск polling:
await dp.start_polling(bot)
```

При завершении приложения желательно отключить Telethon-клиент:

```python
if telethon_client is not None:
    await telethon_client.disconnect()
```

Если в твоём `main.py` уже есть Mini App, веб-сервер и другие обработчики, оставь их без изменений и добавь только регистрацию модуля и запуск слушателя.

## Оплата и автопродление

Подписка оформляется через платёжную ссылку Telegram Stars с периодом 30 дней. Telegram автоматически пытается продлить подписку в следующий период. Команда `/cancel_sub` отключает будущие списания, но доступ сохраняется до даты окончания уже оплаченного периода. `/resume_sub` повторно включает продление, пока оплаченный период активен.

Перед включением настоящих платежей проверь цену, текст условий и команды управления подпиской. Для настройки приёма платежей и финансовых вопросов попроси взрослого помочь тебе.

## Что хранится локально

- `paid_gifts.sqlite3` — подписки и записи подарков;
- `gift_listener_session.session` — авторизованная Telethon-сессия;
- `.env` — токен бота и Telegram API credentials.

Эти файлы не нужно пересылать никому. Никогда не вставляй токен бота, API_HASH, коды входа или пароль в чаты.
